## 4. 驱动必须交出的六种行为

1. 上电初始化失败能报告错误，物理输出不误给允许运动。
2. 有新结果时才发 `available=true`；同一结果只消费一次。
3. 硬件未就绪时迅速返回等待；达到本模块允许的等待上限后报告故障。
4. 总线失败、不足长度或芯片明确错误状态不会产生 `valid=true`。
5. 原始值、单位、状态与时间属于同一次读取；旧值不能刷新有效时间。
6. 恢复后重新初始化/恢复测量的动作有记录；不靠无限重启掩盖反复错误。

这些是本项目的验收合同，具体“就绪/清除标志/状态码”的寄存器或 API 必须从选定路线的资料确定。普通 I²C 地址能应答只证明通信有响应，不能替代这六项。
