# 距离变化趋势提示（2026-10-08）

- 接线不变，主控第一屏右上显示接近/远离/静止，原距离和安全/警戒/故障行保留。
- 从7个新有效测距结果的前后两组均值估算变化速度，使用真实时间差；约0.6～0.8秒窗口，变化>=4cm/s进入接近/远离，<=2.5cm/s回静止，防静止时跳字。
- 无效/300ms断流/故障立即清趋势，需要重新积累；时钟回绕已考虑。此为测距趋势估算，不是对物体真实运动的独立证实，换目标可能短暂产生趋势。
- 本版只提示趋势，不改变已有20厘米默认、旋钮12～50厘米范围、预警声光、测距故障/恢复，也不控制电机。初始数据不足时右上留空。
- UART TREND_STATUS返回有效、类型(0未知/1静止/2接近/3远离)、接近速度mm/s、样本数；速度为估算值，未验收精度。
- 下一步白纸来回移动，观察三种文字；不变化或停止后持续显示接近/远离则停止后续扩展，读遥测查采样与窗口。
