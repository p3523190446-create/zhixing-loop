# 旋钮调节预警距离（2026-10-08）

- 接线沿用A→PD4、B→PD5、VCC→3V3、GND→已验证GND，C留空。
- 实物检测顺10格为-10电周期、反10格回0，累计80相位变化且非法0；软件反转符号，顺时针增大距离。
- 每格1厘米，范围12～50厘米，默认20厘米；退回正常的距离比预警设定大2厘米，防边界灯光抖动。12厘米下限留在已有8/11厘米内部危险阈值以上。
- 转动后第三屏中间行显示“预警xx厘米”，停止5秒返回运行时间，底部视觉状态保持。设定即时生效；断电/复位恢复20厘米，本版没有持久保存。
- 参数改变只改guard.config预警进入/退出两字段，不清故障，不伪造新数据，不改变300ms故障时间或三样本恢复；下一次新真实测距按新参数判断。
- UART PARAM_STATUS：预警mm、退出mm、参数页启用、距转动ms；ENCODER_STATUS仍可读。
- 12～50厘米是参数可调范围，不等于整个区间测距精度均已标定。
- 编译/上板/实物显示以build/r1_encoder_control证据为准，用户转动后的显示与报警行为待验收。
