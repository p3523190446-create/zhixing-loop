# 云台手动响应与扩展范围 · 0.28.2配套

本人反馈0.28.1实物仍慢、范围不足，并明确现车“负俯仰抬头、正俯仰低头”。本次追查发现主控manual_step仍是1微秒/10毫秒；仅手机端提高限速不能消除该瓶颈。此前约半秒的说法只描述手机目标过渡，不能当实物速度结果。

本固件从精确的已部署r1_mecanum_groundmap二进制及源码快照继承，仅改变gimbal_random.h与native_usb.c：

- 手动模式从1提高至40微秒/10毫秒，延迟后不追赶跳跃；随机演示模式不变。
- 手动可接受脉宽500～2500；20毫秒PWM周期、开机零输出、3秒续期和停止处理不变。
- P7能力回执变为GIMBAL_CAPS,2,500,2500,4000；车轮方向映射、身份、巡线与传感源码逐文件相同。

手机0.28.2：默认手动速度4000、指令发送周期50毫秒；保留100%幅度。俯仰显示“- 抬头 / + 低头”，摇杆上拉发负值，下拉发正值；不把本来正确的上拉映射再反转。扩展脉宽配置在旧主控上禁止开启，新固件须通过能力核对。
