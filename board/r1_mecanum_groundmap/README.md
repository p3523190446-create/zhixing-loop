# 麦轮落地方向映射修正 · 2026-11-07

当前固件 `r1_mecanum_groundmap`（V3）、手机 0.26.3/code29 已部署并读回一致。

## 修正依据

用户明确报告已落地：蓝色前后运动正常；蓝色右推使车头右转；橙色右推使车身右移。旧界面的平移与转向指令因此没有对应到实际车身动作。

按这组带正负方向的现场结果，保留标准 X 运动学，在主控接受四轮目标时交换 M2/M4 的输出目标。这在数学上恰好交换旧版横移和旋转两个基向量，前后、零输出及共同限幅不变。**这是按实测结果做的输出适配，不是已经证明两路电机插头接反；实际机械/接线原因仍未核定。** 后续若改变轮组布局或接线，须重新核对这一配置。

修正同时作用于手动 `DRIVE_VECTOR` 和循迹内部 `DRIVE_SET`，在逐通道控制器之前完成一次映射，反馈保持驱动板 M1～M4 的原顺序。未在每次控制循环中重复交换，也没有对调 UI 的文字或颜色。

| 正向指令 | M1目标 | M2目标 | M3目标 | M4目标 |
|---|---|---|---|---|
| 前进 | + | + | + | + |
| 右移 | + | + | - | - |
| 右转 | + | - | - | + |

表中是本车适配后的驱动通道目标，不是通用麦轮安装图，也不代表已测得的车体速度。
