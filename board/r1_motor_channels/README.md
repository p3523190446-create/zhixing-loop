## 已验证与边界

- 驱动板持续回复`$Battery:8.2V#`，当前运行版本RX错误与丢字节均0。
- 三块OLED刷新计数、主控计时和测距采样计数继续增加；原保存记录为250mm、声音开启，启动加载正常。
- 测距本轮RangeStatus=4，无有效测距值，守卫处于FAULT。只证明采样流程继续，不能说本轮距离读数正常。
- 首次旧编号①（程序M3）发送一次PWM900短试转，用户确认轮子转动；实际停止尚未得到明确反馈。随后用户要求完全采用厂家编号。
- 最新M1已发送一次PWM900短试转与3次PWM0停止帧，实际左前轮转动/停止待本人观察。
- 程序只有MOTOR_TEST_M1至MOTOR_TEST_M4四个固定短测命令；启动只发PWM0及查询，不自动发非零运动；无任意电机PWM透传、无自主行驶。
- 每次测试需最近1.5秒内收到有效电压回报、发送队列空闲、无上一轮未完成停止、至少3秒冷却。
- 250ms为主循环开始安排停止的门槛，不是已测实际轮子转动时长。当前每循环只发1字节，记录到第三帧停止完成为460ms（旧M3）/521ms（M1）；不能据此承诺250ms硬实时停车。整车落地前须优化发送及验证失联停车。
- 单轮控制为悬空安装核对，不受测距状态门控；未实施地面主动防撞、闭环速度控制或预测算法。

证据：build/r1_motor_probe/driver-uart-live-check.json；build/r1_motor_channels/flash-motor-verification.json、M1-bench-pulse.json；build/r1_motor_pulse/q1-bench-pulse.json。
