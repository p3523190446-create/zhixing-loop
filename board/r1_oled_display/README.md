# 第一块OLED：单屏兼容性测试

## 型号边界

用户不能确认屏幕尺寸或芯片。目前地址0x3C实际有应答，先按SSD1306、128×64进行兼容性试验；地址不证明型号，芯片身份仍未确认。

驱动参考：[Solomon Systech SSD1306原厂数据手册（SparkFun保存副本）](https://cdn.sparkfun.com/assets/d/a/a/b/c/SSD1306_datasheet.pdf)，使用页寻址和内部升压初始化。后续若画面错位、半屏或乱码，先核屏幕/修改适配，不认定屏幕坏或已确认SH1106。

## 本次界面

- 完整128×64边框和中文标题「知行回路」。
- 距离以厘米显示一位小数，来自此前桌面候选修正；不宣称一位小数的测量精度。
- 安全、警戒、故障，对应既有测距状态。无可信距离显示--.-。
- 视觉有/无只表示CH32是否有未超时的有效视觉包，不代表相机是否在线或识别一定正确。电脑桥接脚本停止后视觉无是预期；不自动恢复长期视觉转发。

PB8/PB9单屏总线，与PB6/PB7传感器分开。每次主循环只传32字节，按250毫秒间隔更新画面；TIM2灯/蜂鸣器中断保留。字体是本机微软雅黑生成的16×16指定汉字子集，未复制整份字体文件。

## 验证

构建build_r1_oled_display.py只编译。flash_r1_oled_display.py COM5核旧OLED探测固件、备份、下载、逐段回读，在线检查OLED_SCREEN返回帧计数增长/ready/错误数及测距更新。

机器回读和显示数据应答不证明用户真的看到正确画面。实物验收须确认：边框完整、文字可读，手靠近/远离时数字与状态随之改变。没有正确显示则停在第一块，不接另外两块。

编译与下载证据：build/r1_oled_display/build_result.json、flash-display-verification.json。下一步等待本人观察结果，再接第二/第三块。
