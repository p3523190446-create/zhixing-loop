# 当前上板：双屏与传感器恢复（2026-10-07）

- 第一块OLED：PB8=SCL/PB9=SDA，距离与安全/警戒/故障，原布局保留。
- 第二块OLED：PB10=SCL/PB11=SDA，视觉识别、类别/中文常见类别、模型分数；不是识别准确率。无当前目标显示无目标；没有新鲜手机帧显示未连接。第三块尚未接入。
- 两块均为独立软件I2C，总线地址0x3C相同也不冲突。SSD1306 128×64兼容驱动；第二块芯片型号和人眼内容未确认。
- 测距通信错误/转换超时：废弃旧距离，最多每秒一次总线解锁和完整传感器重新初始化，重新加载原有13000um偏置。至少三次新有效结果才退出红灯故障。
- 光学质量不合格不会误判为断线而重新初始化。长期无效或硬件持续拉低总线仍保持故障。
- 重初始化调用ST有限轮询，主循环可暂缓；独立1ms告警定时器仍运行，保持故障期间红灯。该桌面原型尚未驱动电机。
- 总线解锁依据：[NXP UM10204](https://www.nxp.com/docs/en/user-guide/UM10204.pdf)，至多9次时钟并发出STOP，硬件仍占线则返回错误，稍后重试。

- MCU编译、完整旧版备份、新版下载及读回、UART握手通过。
- 两屏真实ACK和刷新帧增加，均ready=1/error=0；距离采样持续。
- 实际read_sensor/record_sample源码的主机故障注入回归通过：掉电后需要初始化、初始未接、持续断线重试限速、初始化失败再成功、三次新样本恢复、光学质量、转换超时、时钟回绕。模拟API并非实物证据。
- 用户按SCL/PB6拔线/插回要求答“自动恢复了”。保留本人观察为PASS_USER_REPORTED；之后实读重初始化尝试/成功数仍为0，故本次实测没有证明完整重新初始化分支被触发，不推成所有线/电源故障均已验收。
- 新版真实手机短测3帧ACK，均无目标，UART无接收错误，退出清除旧目标；未证明本轮识别到具体物体。手机运行慢的问题未另行解决。
