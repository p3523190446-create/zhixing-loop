# 当前上板：持续手机同步与自检（2026-10-07）

- 固件r1_phone_monitor；接线仍是距离PB6/PB7，第一屏PB8/PB9，第二屏PB10/PB11，第三屏PB12/PB13；外接PD0/PD1/PD2灯、PD3蜂鸣器保持原实现。
- 第二屏继续显示中文类别与模型分数；第三屏显示运行时间及视觉状态。独立心跳提供原因，绝不将“应用进程存在”当作新识别结果。

| 状态文字 | 含义 |
| --- | --- |
| 转发离线 | 电脑程序没有报告心跳，或超过3.5秒未报告 |
| 手机离线 | 电脑未发现唯一已授权手机，或USB检查过期 |
| 程序未运行 | 手机连接，但本项目视觉应用进程不存在 |
| 无新数据 | 应用进程存在，暂停、后台、卡住或尚未输出新识别帧；不能仅据此判断具体原因 |
| 无目标 | 收到新识别帧，模型没有检测到有效物体 |
| 有目标／类别名 | 收到新的有效目标；第三屏显示有目标，第二屏显示物品名字 |

## 主控协议

- H1,state*CRC8，每秒心跳，state0手机离线/1应用不存在/2没有新帧/3正在接收。
- 主控回复HEART,state；心跳独立于V1识别协议，不能刷新目标有效期。
- 没有新识别数据达到2秒清除旧目标；应用停止、手机离线或无新数据心跳也立即清旧目标。心跳过期3.5秒显示转发离线。
- PHONE_STATUS串口诊断：监控心跳是否有效、状态、心跳年龄、视觉链路与目标是否有效。
- 原测距300ms故障期限、传感器恢复、声光定时不变；main.c、测距驱动和第一屏源码与三屏版一致。

## 电脑程序

- phone_vision/monitor_bridge.py：默认持续运行，无固定时长；每两秒检查已授权手机/本项目进程，每秒发送心跳；手机/应用/主控串口重新可用后重建链路。
- 自动选择唯一WCH-LinkRV串口VID/PID1A86/8010，重新打开后先HELLO握手。串口忙或多个匹配设备时等待，不尝试控制其他设备。
- 新日志流丢弃首条历史日志；之后要求序号和手机时间都递增，丢弃电脑队列中超过0.5秒的消息。只转发新实时推理，空检测也是真实帧。
- 本机仍通过电脑USB ADB转WCH串口，不是脱离电脑的手机直连；电脑睡眠/关机时同步停止。
- 单实例Windows文件锁，后台隐藏运行；monitor_control.py start/stop/status可启动、正常退出、读取状态。工作区根目录提供启动视觉同步.cmd与停止视觉同步.cmd，电脑重启后需重新启动。
- 状态文件output/phone_vision/monitor-status.json每秒更新，最近100帧匹配ACK及最近40条状态变化保留；设备标识不写入日志。输出/错误日志同目录。停止时HELLO清除主控目标。
