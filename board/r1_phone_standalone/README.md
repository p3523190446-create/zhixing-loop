# 手机独立姿态采集与云台跟随 · 0.28.3

## 本轮修正

脱离电脑没有姿态的根因：现车地址0x69、身份0x72的传感器，旧固件每次启动将compat_trial清零，只能由P9临时开启；P7白名单与Android服务没有这项恢复操作。界面还会把已断连的旧错误显示成“待兼容确认”。

本固件从已读回的r1_gimbal_responsive精确二进制继承，只修改mpu6050_probe.c并新增imu_identity_policy.h：本车0x72兼容采集上电自动开启，其他未知身份继续拒绝。采样仍须配置寄存器读回成功、参考匹配和新鲜帧才能显示。0x72不改称原厂MPU6050；现车水平参考与轴方向保持。车轮、巡线、相机和云台主控源码保持。

Android/网页0.28.3：断连时正确显示主控未连接；修正旧“重启不会开启”的提示。云台色块跟随改为默认双轴、已保存的完整范围、自动限速600微秒/秒（手动4000保持），沿用相同当前姿态交接、250ms帧有效期、1500ms页面续期、车辆互锁与丢目标撤销。
