- 原SG90三孔插头保持完整，三根公对母杜邦线转接：棕→主控GND、红→主控+5V、橙→PA8。用户确认按此接好，并确认USB接P9、开关ON、驱动电池断开、另一舵机留空。

## 输出和命令

PA8/TIM1_CH1：1MHz计数、20ms周期（50Hz）。上电CCR为0，只有显式命令才启动，结束后CCR回0。TIM2毫秒中断处理期限，主循环/串口停止轮询不负责维持期限。

- SERVO_CENTER：1500us，1000ms后停PWM。
- SERVO_WIGGLE：1500→1400→1500→1600→1500us，每段200ms。
- SERVO_WIDE：1500→1300→1500→1700→1500us，每段500ms，2500ms后停PWM。用户要求增加幅度后新增并实测。
- SERVO_STOP：停止脉冲；这不是切断舵机5V电源，不能保证任意舵机副本失去力矩。
- SERVO_STATUS：毫秒、就绪、活动、脉宽us、启动次数、停止次数、计数器Hz。上述脉宽不代表已校准机械角度。

运动指令MOTOR_仍全部拒绝（MOTOR_STOP除外），没有车辆运动请求。俯仰轴GPIO尚未分配。
