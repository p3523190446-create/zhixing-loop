# 预警距离记忆

- 原接线保留。USER短按并松开切换静音；连续按住约2秒保存预警距离，一次长按只保存一次，不触发静音。开机握住按键先释放再用。
- 第三屏提示保存中、已保存NN或保存失败；成功提示约4秒。重启自动恢复最近有效参数，短暂显示已恢复NN；静音不保存，重启默认有声。
- 存储范围仅末尾两个4KB扇区（7FE000与7FF000），两份交替，CRC32与最后单字节提交标记；不自动格式化未知内容，不整片擦除。
- 未写使能/忙检查失败则报错；擦除/编程每2ms轮询，1500ms限时，测距与UART继续。只在成功读回提交记录后提示保存成功；重复保存同值跳过写入。
- SETTINGS_STATUS供诊断；SETTINGS_READ,offset只读预留区32字节，主机安装流程先备份8192字节。无远程写入命令。
- 掉电保护在模拟NOR测试；实际保存与重启仍需本人验收，不能用主机测试冒充物证。
