# 当前记录保存：预警距离＋静音模式

- USER短按并松开只切换静音；连续按住约2秒保存长按触发瞬间的预警距离和静音/有声模式，两项为一份记录。
- 重启恢复最近成功保存的两项；未经长按保存的更改不替换存档。无存档时默认20厘米、有声。
- 第三屏成功/恢复提示保留距离，右上附静音或有声；第一屏静音提示维持。
- 旧v1距离记录兼容读取，模式按有声；不自动擦写或改掉已保存的距离。下一次物理长按生成v2，CRC覆盖两项。
- 同值判断比较距离和模式，单独改变模式也会写入；最后两扇区交替、提交字节与校验、限时后台轮询保留。
- 设置只由USER长按保存，无串口写入命令。SETTINGS_STATUS末尾新增saved_muted字段。
- 模拟掉电不代表实际断电过程全覆盖；新实物静音保存与重启恢复待验收。
