# R1 存储模块只读识别

- 模块近照印字 Winbond 25Q64FVSIG，VCC接3V3、GND接已验证地。
- CS→PA3、DO→PA6、SLK→PA5、D1→PA7；KEY→PA4跳线保留。
- 软件SPI模式0，5微秒半周期，1毫秒中断保持开启。
- STORAGE_STATUS 每次重新读取JEDEC与两个状态寄存器；返回ID、SR1、SR2、采样次数、匹配次数、当前匹配。
- 只发送9F/05/35只读指令，无写使能、擦除、写入、参数保存。
- 预期JEDEC 0xEF4017，实际通信待上板验证；该编号不独立证明芯片真伪或全部容量。
- 保留三OLED、测距恢复、旋钮、趋势、短按USER静音。型号不符则停写入阶段并查接线。
