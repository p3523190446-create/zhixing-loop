# 固定前向超声波读取测试版

2026-10-13，基于已上板r1_motor_dashboard_no_knob，单独保存源码和编译目录。

- HC-SR04/CS100系列：B板A23地、B23的3V3试测；Trig→PD12，Echo→PD13。用户已确认四线接好，驱动电池断开。
- TIM4内部1MHz计数器，无PWM/引脚重映射；PD13映射EXTI13双边沿中断。TIM2原毫秒时基增加35ms超声超时与300ms数据过期检查，保留三屏、ToF、声光及USER。
- 每次触发间隔至少100ms，脉冲12us；回波100–18000us才接受。距离换算使用343m/s室温近似，未经温度修正或距离校准。
- 此测试版拒绝MOTOR_命令族（MOTOR_STOP除外）；无云台/舵机控制。超声数据尚未用于声光或运动防撞，第一OLED仍显示原ToF距离。
- 没回波、迟到回波、脉宽异常、过期均不能当0厘米/无障碍。轮询不会等待回波，主要时限由TIM2中断执行。

串口ULTRA_STATUS返回：`ULTRA,毫秒,有效,状态,距离mm,脉宽us,触发数,成功数,超时数,边沿数,拒绝数,距上次成功ms,计数器Hz`。
状态0未采样、1有效、2超时、3回波卡高、4脉宽范围异常、5过期。

## 实际结果

固件已编译、备份前256KiB旧程序、烧录、逐字节读回核对，并重新启动。原固件备份及flash-verification.json在build/r1_ultrasonic_probe。

1. 首次读回10/10有效：130–131mm；未得到精确实体参考距离确认，不能称20厘米点验收。
2. 用户摆约10厘米后10/10有效：[114,114,114,114,124,124,124,114,124,114]mm，存在波动与参考偏差。
3. 三屏通信返回ready=1/errors=0；ToF返回初始化错误0、状态0、距离57–58mm。仅通信/瞬时数据证据，不称完整显示或连续稳定验收。
4. 用户选择结束本轮，没有进行30厘米点、无回波故障实物测试、供电实际电压/回波电平测量、补偿或地面运动。

电脑边界测试使用实际ultrasonic_state.h，已覆盖16位计数器绕回、35ms超时、迟到回波、错误边沿、卡高、异常短脉冲、300ms过期及毫秒计数绕回。该测试不代替实物。

停止条件：供电/线序不明、发热、重启、原功能退化时断USB；驱动电池继续保持断开。下一步先核双舵机云台5V供电和控制引脚，用户恢复超声测试后再检查距离变化/准确度。
