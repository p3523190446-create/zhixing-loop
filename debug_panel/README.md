# 知行回路调试台

独立的本机只读网页，每秒读取已有后台输出。不打开串口、不启动ADB或OpenOCD、不下载固件、不控制电机、不改变现有转发程序。

## 使用

双击 `启动调试面板.cmd`。窗口显示网页地址，浏览器打开后可查看总览、历史固件验收与调试日志。关闭该命令窗口即可结束面板服务，原后台程序不受影响。

## 数据边界

- 手机与开发板连接状态来自 `output/phone_vision/monitor-status.json`。只有文件内UTC时间距今不超过5秒且running=true，才作为当前报告显示；不是硬件连线独立检测。
- 视觉结果来自 `monitor-recent-frames.json` 内开发板确认报文；无目标cls255与手机离线分开显示。模型分数不表示识别一定正确。
- 固件验收来自项目登记的固件目录。通过项和当时的距离均为历史记录，不能代表目前设备状态。
- 实时距离、预警距离、声音模式尚无持续后台数据源，页面明确显示待接入，第一版不画假曲线。
- 日志仅显示末尾100行，每个文件标注更新时间。无新日志不表示正在调试。
- 只监听127.0.0.1，API不接受命令或任意文件路径。
