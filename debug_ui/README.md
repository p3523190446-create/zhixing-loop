## 打开和运行

**iPad展示方案：** iPad与小安卓连接主力iPhone热点，iPad Safari横屏打开小安卓网址的`/desktop`入口；iPhone负责拍摄。用户已确认iPad可打开且横屏界面正常。分工、地址与拍摄期间验收见 [iPad演示操作.md](iPad演示操作.md)。本次复用已安装应用入口，不需要重装或电脑转发。

**车载演示入口已迁至小安卓应用“知行回路调试台”（cn.zhixing.dashboard）**。小安卓连接iPhone热点，打开应用；iPhone从桌面单独打开Safari，访问小安卓顶部显示的完整地址。2026-10-13用户确认拔掉电脑USB后页面仍可刷新、切换“运行状态／记录回放”。此项只验收两手机网页访问，不代表主控、摄像头或遥控已在新包联调完成。热点重连后IP可能改变，请读应用地址。细节见 [android/README.md](android/README.md)。

电脑开发入口读本目录 `runtime.json`：`desktop` 电脑版、`mobile` 手机版、`url` 自动适配。演示地址单独在 `demo-runtime.json`，每次启动会生成新地址。演示有显著模拟标记，完全不访问实物。

启动真实接口版本：双击本目录的 `启动调试台.cmd`。它只启动 UI 和接口代理，不抢占 COM、不烧录、不自动开云台、画面或录像。现有 `remote_panel` 服务仍负责实际通信、租约和日志。该服务不可用时，页面显示离线，数值清空，控制不可开启。原页面及固件没有改动。

手机与电脑同一局域网时，使用启动窗口打印的“手机地址”。手机里的 `127.0.0.1` 是手机自己，不能填电脑的回环地址。LAN 地址打印是连接候选；本机防火墙、路由器隔离、实机浏览器和供电尚需实测，不自动更改防火墙规则。关闭启动窗口停止 UI 服务。

命令行也可运行：

```powershell
& 'C:\Users\panyuanhao\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' '.\server.py' --bind 0.0.0.0 --port 8772
# UI 交互演示：不接硬件，不访问现有后台。
& 'C:\Users\panyuanhao\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' '.\server.py' --demo --port 8771
```

地址中的随机路径需完整保留。当前 UI 代理从 `../remote_panel/runtime.json` 读取最新本机服务地址；旧服务重启后不需要改前端。只有固定白名单接口可代理，没有任意串口命令、车辆运动接口或任意磁盘文件读取。

## 功能封装

用户现已要求先保留低延迟方案。当前修订源码默认HTTP轮询，只有显式`?transport=ws`才启用`assets/core/realtime.js`及`android/RealtimeChannel.java`预览；普通入口保持原1000ms轮询和200ms摇杆合并。实时预览使用10Hz推送、50ms合并并分别显示网络RTT和源数据年龄；手机/CH32端到端延迟尚未实测。修订源码不等于手机已更新，安装与验收记录另核。见 [低延迟通信说明.md](低延迟通信说明.md)。

| 文件 | 职责与接口 |
|---|---|
| assets/core/api.js | HTTP 请求、超时、二进制画面、离开页面通知；get/post/image/beacon。以后接车载手机服务只更换此通信适配层。 |
| assets/core/dom.js | 格式化、范围约束和 DOM 工具。 |
| assets/features/navigation.js | 三个功能页、布局入口、导航和重排；切页不自动停云台，整页进入后台才请求停止。 |
| assets/features/gimbal.js | 开启回执、唯一会话、触摸/鼠标/键盘、两轴微调、幅度、回中、停止、心跳、撤销过期指令。 |
| assets/features/camera.js | 实时画面、画质/FPS 自动应用、目标与实际FPS区分、帧过期处理、录像切换协调。 |
| assets/features/recording.js | 开始、保存、状态、历史列表、切换续录资格。 |
| assets/features/replay.js | 历史视频、播放/暂停、时间定位与状态对齐；只调用读取接口，没有实物写入。 |
| assets/features/telemetry.js | 测距、超声、电压、阈值、运行时间、四轮与故障数据的有效性和新鲜度显示。 |
| assets/features/chart.js | 60次更新的距离曲线，无效读数与断线留缺口。 |
| assets/features/diagnostics.js | 底部折叠日志、记录会话、事件/分段计数、错误；不改写原始记录。 |
| assets/app.js | 初始化、轮询及页面生命周期协调，不混入功能业务实现。 |
| server.py | UI 静态资源与现有接口代理，完全不打开串口。 |
| demo_backend.py | 明确模拟的交互验收后端；只能用 --demo 启用。 |

功能模块通过明确接口协作，例如相机切换调用录像的 stop/start，不依赖其他模块的私有变量。两端共享模块，避免电脑版修好而手机版仍保留旧逻辑。

## 适配方式

电脑版宽屏左右并列画面和控制；窄窗口同样重排，不强制横向滚动。手机版竖屏依次排列，底部三页导航，固定停止云台按钮，按钮/选择框/滑条触摸高度至少44 CSS像素。240–350窄屏再重排摇杆与幅度；横屏自动用宽屏布局。保留缩放，适配安全区域，离开页面请求停止并保存本页记录。对较旧 Android 的画面高度与安全区域提供 CSS 回退。

网页现已内置Android APK，手机服务不依赖电脑代理。旧carconsole 0.2的P7只读通信、后台记录与停止保存已实测；dashboard复用其源码，但新包USB尚未实测。当前P7固件拒绝云台写指令，因此Android接口和网页均禁用云台控制。相机、录像代码已实现，仍待新包实测；不能以模块实现代替硬件验收。
