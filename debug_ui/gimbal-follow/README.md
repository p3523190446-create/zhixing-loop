用途：车轮停止后，让车载相机跟随一个红、绿或蓝色色块。识别在小手机本机运行，不依赖电脑大模型。

## 使用过程

1. 连接主控并开始记录，打开相机，选择目标颜色。
2. 在同一页面开启手动云台，对准目标，等待云台停稳、画面显示连续跟踪。
3. 核对实际安装方向和可活动空间，勾选确认，点击“交给自动跟随”。默认只跟随水平方向。
4. 若目标移动后偏差持续增大，停止跟随，再修改对应轴方向。方向正确后再选水平＋俯仰。
5. “停止跟随”停止该页面持有的跟随会话；原云台停止按钮仍可全局停止。切回手动需重新点击手动控制。

交接沿用当前控制脉宽，不重新发开启命令、不回中。跟随范围取交接位置左右各150微秒，并裁剪到原已设置边界；速度上限30微秒/秒。脉宽是控制值，没有舵机角度反馈，不能写成已测角度。

## 保护与局限

- 仅接收250毫秒内、连续锁定的目标结果；换目标、换颜色、暂停视觉、相机断开或结果过期会撤销跟随。
- 页面每400毫秒续期，1500毫秒无有效续期就撤销；离开画面页、隐藏页面或收起云台控制也请求停止。页面恢复、目标回来均不自动重启。
- 车辆运动、循迹或标定状态不适合时拒绝启动；跟随期间拒绝新行驶和循迹启动。车轮原有独立故障保护不因此自动验收。
- 停止指令须由主控返回停止和零输出才记为确认；主控断开时标记“停止回执未确认”。
- 单一目标颜色跟踪会受光线、相似颜色、遮挡影响，不能当作人物识别、身份识别或任意物体跟踪。
- 软件范围和确认勾选不能代替真实方向、机械活动范围的实物核对。

## 实现与来源

复用现有 PhoneColorTracker 的本机 NV21 色块定位与目标锁定。GimbalFollower 只计算受限目标；ControlBroker 统一执行、续期、主控回执和手动交接，不另开一条串口控制通道。PhoneVision 仍是观测接口，自动执行状态单独看 gimbal-follow/status。

借鉴官方开源云台示例的“画面偏差→限速调整”思路：

- https://www.waveshare.com/wiki/2-Axis_Pan-Tilt_Camera_Module
- https://www.waveshare.com/wiki/Pan-Tilt_HAT

本工程未移植整套示例框架；边界控制与既有主控协议由本工程适配。

## 构建、检查与安装

原构建入口仍为 debug_ui/build_android.py。版本0.28.0，versionCode 33；页面新增 mobile-0280 入口，旧入口保留。未修改或烧写主控固件。

- run_gimbal_follow_checks.py：在已连接 K99 的隔离 app_process 中运行生产类及模拟主控。包含跟随计算、限速限位、旧会话撤销、失帧、超时、车辆状态变化和原手动标定回归；不访问USB或真实舵机。
- check_gimbal_follow_webview.cjs：经ADB本地调试通道检查实际手机 WebView；不打开外部浏览器、不启动真实控制。
- tools/install_gimbal_follow.py：复用已有安装器，备份旧APK、install -r、读回核对，核对 web、gimbal_profile、line_calibration、large_vision 四份设置哈希。

构建与检查记录：output/onboard_dashboard/gimbal-follow-20261107。含配对地址、旧APK和本机运行信息的记录目录是私人验收证据，不直接整体作为公开源码包发布。
