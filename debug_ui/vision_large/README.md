# 知行回路 · 大模型看图

让小车的真实相机拍一张图，交给电脑上的视觉语言大模型，用中文描述物体、颜色、位置并回答问题。网页保留本次原图、模型名称、请求耗时和可下载的JSON记录。

## 怎么用

1. 电脑与车载小手机连接同一个热点。电脑运行Ollama，保留已经安装的 `qwen3-vl:8b-instruct`。
2. 运行 `知行回路软件/tools/start_large_vision.py`。它复用已有8797服务，不打开串口、不启动电机。
3. 小手机接原车相机与集线器，打开原App的相机预览。
4. 打开原车载网页。在相机下方点“大模型看图 → 识别当前画面”。可修改问题后重新拍图。

0.27.2起，浏览器统一调用小手机的同源模型接口，小手机转发到电脑；平板不用直接请求电脑模型端口。模型服务完整地址保存在车载App的 `large_vision` 设置中，手机/平板/电脑新打开的页面会自动读取。模型服务地址随电脑IP或服务路径变化时，在任意一个车载页面的“模型连接与照片分析”里重新连接一次，再刷新其他页面。地址为空或连接失败时不开放识别，不再显示浏览器英文URL错误。

曾打开旧版的平板可使用车载网址后面的 `/mobile-0272` 入口，页面和模型模块带版本标记。出现“由小手机统一转发”表示已加载本版模型连接方式。

也可以在电脑打开启动时显示的大模型专用页面，选择一张照片分析。手选照片会明确标注，不当作实时相机；手机系统照片选择器已接入，但其系统交互需要另外实机核对。

## 数据经过哪里

```text
原车USB相机 → 小手机UVC采集 → 车载网页取一张新快照
                                    ↓ 同源提交本次快照
                          小手机模型请求转发接口
                                    ↓ 同一热点Wi-Fi
                         电脑8797只读图片服务
                                    ↓ 电脑回环地址
                        Ollama / Qwen3-VL 8B
                                    ↓ 由小手机转回
                      网页显示本次原图、回答和耗时
```

P7承担小手机与CH32通信，本功能不要求P7传图片，也不要求电脑直接枚举插在手机上的USB相机。模型在电脑本地运行；基础车控和色块处理仍在小手机上。这一版不属于“手机离线独立大模型”。

## 实现与复用

- `model.py`：复用鸿蒙项目 `robot_service/adapters.py` 的Ollama图片调用方式，仍使用原来已经安装的视觉模型；没有把整套鸿蒙工程复制进来。
- `server.py`：独立、单任务图片分析服务；固定调用本机Ollama，不读取P7/P9、不导入电机或云台控制模块。
- `../assets/features/large-vision.js`：桌面和安卓共用的取图、提问与结果视图。相机快照与手选照片分别标注；结果始终绑定本次图片，不画到不断更新的新预览上。
- `../android/LargeVisionSettings.java`：所有浏览器共用的连接地址；只接受本机/私有局域网HTTP地址及完整配对路径。
- `../android/LargeVisionProxy.java`：只转发模型状态、图片任务和任务结果，不转发任意URL或车辆命令。浏览器不需要对电脑端口进行跨域请求。
- `tools/install_large_vision.py`：复用已有保留数据的安装器；备份旧APK，升级、回读核对，并检查web/云台/循迹三份既有设置哈希不变。

协议来源：[Ollama图片输入说明](https://docs.ollama.com/capabilities/vision)、[聊天API](https://docs.ollama.com/api/chat)。模型身份以实际Ollama `api/show` 回读为准，本轮是qwen3vl、8.8B、Q4_K_M、具备vision能力；模型权重继续由Ollama管理，不打进源码或APK。

## 结果和限制

服务保留原始图片字节、SHA-256、问题、来源、帧序号、取图/提交时刻、回答、耗时和失败原因。当前记录位于 `比赛项目计划/output/onboard_dashboard/large-vision-20261107/events`。

`captured_at` 是浏览器取到快照/提交照片的时间，不是相机曝光硬件时标。当前接口只接收新鲜相机画面；返回回答时仍标明它针对历史快照，不能当作实时路况。断网/超时/输入无效时报告失败，清空旧回答，不编造新结果。

单张图的文字、品牌、距离、隐蔽物体仍可能判断错。即使主要物体说对，也不等于文字识别或通行能力可靠。模型没有车辆动作权限；避障、跟随、麦轮方向与大模型识别分别验收。

本轮冷请求约34秒，若干预热请求约2—13秒，实车新图个例约3.45/4.08秒。这些是不同输入与加载条件的个例，不是通用速度承诺或准确率。

## 复查

需要Python和Pillow；不需要新增模型权重、云端密钥或收费API。

```powershell
# 本目录：输入、并发、失败和来源边界测试（使用明确的测试夹具）
python -m unittest test_server -v

# 项目tools目录：通过真实模型验证，不启动车辆
python verify_large_vision.py
python verify_large_vision.py --camera
```

`check_phone.cjs` 使用真实K99 WebView和LAN模型服务，所用内存File是明确标注的测试图，不冒充相机。最终实拍和本人确认以对应验收JSON及交付说明为准。

提交源码时包含本模块、共用网页代码及安卓源码；不要包含运行时配对地址、`*-private.json`、个人设置、原始房间照片、旧APK备份、模型权重或SDK。新生杯与鸿蒙共用模型服务，不代表两项比赛各自已完成验收。
