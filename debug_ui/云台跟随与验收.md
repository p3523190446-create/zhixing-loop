# 云台色块跟随 · 0.28.7

0.28.7新增：跟随区逐项显示主控与停车、色块锁定、云台准备、确认勾选四项状态；修复K99旧版WebView退出页面时的sendBeacon异常。只更新手机，不重烧主控，实车仍由本人调控验收。

这项功能让云台追随红、绿或蓝色色块，使目标尽量留在画面中央。它不是人物身份识别，也不驱动车轮。

## 本人实车验收

1. 小手机接回原集线器、相机和P7，开始主控记录，刷新网页；保持“画面与控制”页前台。
2. 点击四驱停止，结束手动行驶或自动循迹。只松开车轮摇杆仍可能持有行驶会话，不能直接开启跟随。
3. 开启相机、选择物体颜色，让一个明显色块进入画面，等待“连续跟踪”。勾选停稳与范围确认，点击“从中位跟随”。已有本页手动控制时按钮为“交接并跟随”，沿用当前位置。
4. 将物体在镜头前缓慢左右、上下移动，先保持在画面内。看实体镜头是否向目标转动，画面偏移是否回落；若越追越偏，停止后切换对应轴的正常/反向再试。
5. 拿走物体应撤销跟随；放回后不得自行重启。重新开始后，点击停止跟随或全部停止，应停止云台输出。收到停止回执后才记为确认。

通过标准：实体云台能在左右、上下两轴跟随同一色块；丢目标会撤销且不自行重启；手动停止有效。单有目标框、状态“已锁定”或控制脉宽变化，不算实体跟随通过。实际机械动作由本人观察。

## 本轮修复

- 原启动依赖同页先开手动，容易只完成视觉观察。现在有本人保存中位时可直接开始；仍支持手动对准后交接，等主控停稳才交接，不改中位与范围。
- 原启动期间的迟到状态可能清掉刚获得的会话，停止续期。现在准备期间暂停观察请求，并隔离旧状态。
- 明确显示未就绪原因：主控未连接、仍有四驱会话、循迹/标定进行中、车轮未归零或故障。
- 页面离开或迟到请求只撤销自身持有的会话；全部停止仍保留全局停止能力。
- 保留0.28.5的平稳操控、手机有界续期、现场标定、大模型照片分析、姿态与手动云台。
