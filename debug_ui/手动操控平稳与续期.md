# 手动操控 0.28.5

已安装小手机0.28.5/code38，APK拉回SHA-256一致，四份原设置及地砖/黑线标定保留。主控仍为r1_phone_standalone，本轮未刷写或主动发机构运动。

## 回到车上怎么用

1. 拔掉连电脑的USB线，小手机接回原集线器，主控P7和原车相机接集线器。
2. 在小手机App连接主控、开始记录。平板刷新原来的调试台，看到“平稳操控”默认勾选。
3. 用20%档开启遥控，轻推左杆试直行和横移，再轻推右杆试旋转。松开归零，停止并锁定结束会话。
4. 若仍持续绕圈、方向反了、无反馈或报电机故障，先停止，保留记录查看。不要通过取消故障保护掩盖。

## 本次修改的实际含义

最新真实运行日志1794035718285-f0d369ee中，USB采集持续且未记录USB断开；多个网页控制包间隔607/626/718/798毫秒，超过主控600毫秒矢量期限，随后DRIVE_REJECTED。不能将这些误报为USB物理断线。另有50%档、满转向指令，会使光滑地砖上的麦轮运动更猛。

小手机现在每120毫秒续发最近有效矢量，浏览器序号与主控序号分开。续发不会刷新用户输入时间；操作输入900毫秒未更新会STOP。小手机到主控本身失联，主控600毫秒停车仍保留。硬件拒绝不自动重新ARM；恢复后需本人重新开启。真正页面隐藏/离开仍STOP；普通焦点变化先归零并保留会话，必须重新触摸才运动。

平稳操控默认开启：速度上限30%，摇杆中心12%死区及柔和响应，平移和转向限制起步变化率，转向输入最多原来的55%，换向先归零，单轴松手立即给零指令。此处“立即”指请求，不承诺机械停止距离。取消平稳操控可回到直接响应及原100%上限。

这是输入整形和有期限续期，不是轮胎打滑识别、航向闭环或固定朝向平移循线。地面抓地力和轮间差异仍需实车验证。
