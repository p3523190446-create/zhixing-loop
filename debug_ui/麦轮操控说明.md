# 麦轮怎么操控

> **当前更新 0.26.3（2026-11-07）**：用户落地发现蓝色左右实际转向、橙色实际横移，且两路向右均对应右向动作。已按此修正主控输出映射，手机新版已安装读回，保留界面预期：蓝色平移、橙色转向，前后控制保持。手动与循迹接口同步适配；修正后尚未落地复测。详见 `board/r1_mecanum_groundmap/README.md`；下方0.26.2为界面设计与历史验证记录。

侧移就是车头仍朝前，整辆车向左或向右挪；转向是车头改变朝向。这是两个可以独立控制的动作。

麦轮边缘的小滚子斜着安装，四个轮子组合正反转和速度，让不同方向的推力抵消或合成，因此不需要先把车头转过去，也能侧向、斜向移动。运动学参考：[WPILib 官方麦轮原理与操作图](https://docs.wpilib.org/en/stable/docs/software/hardware-apis/motors/wpi-drive-classes.html#mecanum-drive)。

## 新界面 0.26.2

- 左侧“平移”摇杆：前后、左右和任意斜向，方向连续变化，不只八个固定方向；轻推小指令，推远大指令。
- 右侧“转向”摇杆：左右拨动控制车头转向；左侧保持回中时就是原地转向。
- 双指同时按住：可以一边平移，一边转向。松开左边，只清掉平移；松开右边，只清掉转向；全部松开，主控收到归零制动。
- “八方向按键”提供直观的固定方向。“归零”保持遥控会话并停止；“停止并锁定”撤销会话，需重新开启后才可继续。
- 方向以车头为准。车头转向后，左摇杆向上仍然表示新的车头前方。当前没有承诺固定世界方向或自动保持绝对朝向。

界面中的三幅示意图分别说明前进、侧移和原地转向。“当前手势”显示用户正在给出的操作意图，不是测得的车体运动。

## 本轮实际验证

原工程内修改控制卡、双输入组件和样式，其他模块保留。浏览器43项假接口检查通过，包含连续角度、十个方向组合、双触点输入、独立松手、全部松手制动、键盘组合、普通轮固件降级、窗口失焦、320/390/768/1280宽度。双触点测试使用Chromium触摸输入，单指抬起使用受控PointerEvent；不冒充本人真机手指或地面实测。

Android 0.26.2/code28已签名构建、安装及拉回哈希一致；保留网页、云台、现场标定三份XML字节一致。真实K99 Chrome66 WebView已初始化新组件，PointerEvent/捕获API存在，解锁后非零视口无横向溢出。初次布局检查时手机处于无密码锁屏，WebView视口为0，解除普通锁屏后同一包检查通过，没有为此更改页面或绕过密码。

本轮没有刷主控或发送车轮/云台动作。固件仍为上一阶段已悬空验证的r1_mecanum_integrated；地面横移、滑移与跑偏、双控手感、手机P7+相机并发均需另验。独立驱动线失联停车问题也没有由UI修改解决。
