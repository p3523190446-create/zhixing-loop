# 单人演示：iPad展示，iPhone拍摄

2026-10-13用户选择。演示不带电脑，不需要另购展示设备。

| 设备 | 分工 |
|---|---|

| 车载小安卓 | 运行“知行回路调试台”、提供网页与接口、存放记录 |

## 打开

1. iPhone开启个人热点，小安卓和iPad都连接这个热点。
2. 小安卓打开“知行回路调试台”。若正在USB诊断，先等诊断结束，不抢占手机应用。
3. iPad横放，打开Safari。使用小安卓显示的完整网址，将最后的`/mobile`改为`/desktop`，其余保持一致。
4. 切换“画面与控制／运行状态／记录回放”，检查页面可用。用于当前演示的地址为：

   `http://172.20.10.8:8780/6f8e7ddd60c24c1aab6502f9f8a80410/desktop`

5. 热点重连可能改变小安卓IP，以应用显示的新地址为准。可以把当前地址加入Safari书签，地址变化时更新书签。
6. iPhone切到相机拍摄时，保持热点开启。正式演示前，拍摄约10秒，同时在iPad刷新或切页，确认访问继续正常。

`/desktop`和`/mobile`提供同一组功能模块、连接同一台小安卓服务。电脑版入口在大屏上使用双栏布局；手机版入口会在大屏上限制成手机宽度。两者不会复制一套独立业务逻辑。
