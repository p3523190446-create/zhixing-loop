# 0.7：摄像头接开发板，手机同时收图和控制云台

## 接口与接线

所有改线在断电时操作。电机电池先不接，舵机电源先不接。

| 设备或信号 | 接到哪里 |
|---|---|
| 摄像头原配USB插头 | 现有转接头 → 开发板P6／USBHS |
| 车载小手机 | 原OTG → 数据线 → 开发板P7／USBFS |
| P9／WCH-Link | 手机运行时留空；电脑烧录时才用 |
| 原测距模块SCL | 从PB6改到J4标PD14的公排针 |
| 原测距模块SDA | 从PB7改到J4标PD15的公排针 |
| 测距模块VIN和GND | 保留原来已经测通的接法 |
| 水平舵机信号 | PA8，保留原接法 |
| 俯仰舵机信号 | PB0，保留原接法 |
| 舵机电源 | 本轮先不接，联合供电尚待实测 |

PB6/PB7现在用于P6摄像头，不要把测距线插回这两针。板底与金属底盘保持绝缘，线束留余量，不遮镜头、不碰轮子。

## 手机操作

1. 打开「知行回路调试台」，顶部版本为0.7。
2. 「连接主控」→「连接主控并开始记录」，系统USB弹窗点允许。
3. 距离和运行时间更新后返回主页面。
4. 在摄像头区域点「开启画面」。主控转发会自动选160×120、5帧目标；实际预览速度另行显示，不能把目标5帧当实测值。
5. 首轮只看画面是否连续更新，并试「关闭画面」后重新开启。不要启动电机。

这个低分辨率版本用于打通双USB通道；手机直连相机原来640×480的效果仍是独立测试，不能当作本路线效果。

## 停止条件与记录

- 手机或开发板反复重启、掉电、明显异常发热：拔下手机OTG停止。
- 出错时保留完整提示；不要同时打开旧自检占用USB。
- 如果重连遇到原来的问题，可以按已知临时方法拔插一次。本轮不宣称重连根因已修复。
- 结束时关闭画面、结束本段记录，等保存完成，再断开主控。
- 原始主控收发和指令回执写入车载记录；摄像画面录像需在记录区域开启，画面与主控事件使用手机时钟记录接收时间。不能承诺记录没送到手机的数据。

先完成无舵机负载的同接画面验收，再接回两只舵机供电验证云台与画面同时工作。手机OTG同时给主控、相机和舵机供电的稳定性仍待验，不并接电脑USB补电。
