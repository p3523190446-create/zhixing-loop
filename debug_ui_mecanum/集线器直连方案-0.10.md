# 外接摄像头和主控同时接手机 · 0.10

2026-10-14：用户选择重新考虑集线器。软件已安装；集线器尚未购买/核验，联合运行未通过。

## 接法

```text
小手机 → 原来的OTG → USB数据集线器
                         ├─ 摄像头原配USB插头
                         └─ 原来的数据线 → 开发板P7／USBFS

开发板P6、P9留空；ToF保持J4 PD14／PD15。
主力手机通过热点或能互通的Wi-Fi访问小手机显示的网址。
```

USB集线器负责接两个设备。摄像头画面由小手机处理、记录；主控反馈仍由P7读取。手机的运动请求仍须经过CH32审核。

## 选购条件

| 项目 | 要求 |
|---|---|
| 用途 | **USB数据集线器**，可同时识别两个设备；不是充电分线器 |
| 上行接口 | 能插到现有OTG头；通常是USB-A公头，须核对商品接口图 |
| 下行接口 | 至少2个USB-A数据母口，4口可以留余量 |
| 速度 | 至少USB2.0高速480Mb/s；USB3.x可以向下兼容，不能因此承诺摄像头更快 |
| 供电 | 优先可单独供电的型号。须核对供电输入要求和上行电源隔离，不把充电插孔当数据口 |
| 兼容与退换 | 核对支持Android OTG及UVC摄像头、USB串口同时使用，并保留实际测试不兼容时的退换条件 |

关键词：`USB数据集线器 USB-A 4口 独立供电 Android OTG`。

摄像头、开发板、双舵机的供电预算须另核。第一轮仍断电机和舵机电源；不直接用7.4V电池接USB供电口，不同时接P9电脑电源。集线器外部供电不等于手机支持OTG同时充电，也不等于会修复P7断连。

资料：[Android USB主机说明](https://developer.android.com/develop/connectivity/usb/host)、[厂商对有源与总线供电集线器的说明](https://www.startech.com/en-au/usb-hubs/st4202usb)。这些资料不构成本手机与某商品兼容证明。

## 软件和验收顺序

1. 现装**调试台0.10**：摄像头只选择手机上145F:02EC设备，P7的1A86:FE0C不会被当摄像头；摄像头不在就明确提示接集线器，不自动选择CH32低分辨率转发。
2. 拿到集线器后先接上述两支，P6/P9留空，电机和舵机断电。USB设备列表应同时看到145F:02EC、1A86:FE0C。
3. 开始主控记录，再选640×480、目标15帧打开画面。先观察两个数据源同时更新，随后测实测预览帧率、延迟、连续记录及中断状态。**目标15帧不是已达到15帧；720P/1080P/60帧均未保证。**
4. 视频与主控同时稳定后才接云台电源，最后才进入地面运动。

停止条件：设备消失、发送失败、画面长时间冻结、掉电或重启时结束本轮并保留原始日志；不反复开始，不自动恢复运动。

## 为什么改路线

0.9手机回读记录：无画面段41.294秒／410次状态回复后，STATUS发送返回-1；带画面段53.276秒／530次状态回复后同样失败。失败前有授权，系统设备移除通知晚于失败，具体根因尚未确认。

带画面段完整传输15帧；首末完成帧之间平均约**0.619张/秒**。这是完整帧交付速率，不是摄像头曝光采集帧率，也不是屏幕显示测量。现实现固定160×120、8192字节帧上限、64字节HEX分包逐次查询、与一秒一轮的主控状态共享线程，不能通过下拉框变成高清流畅视频。

0.10改变视频路线，保留P7传输原实现，**未修复自动断连**。没有摄像头时也不影响主控单独记录；没有主控时画面可单独预览，云台控制不可用。后续USB稳定性仍是必须验收的独立项目。
