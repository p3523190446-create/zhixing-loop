# 外接USB相机：手机独立预览与回接电脑诊断

手机测试软件包为`cn.zhixing.uvcpreview`，与原有内置相机视觉应用和USB枚举自检分开。没有电机控制、CH32通信、网络服务、YOLO推理或连续视频录制。本轮目的为取出真实外接画面并保存可回读的诊断。

## 当前实测

- 相机：`145F:02EC / HDI Webcam USB`，SONiX SN9C2279系列芯片。电脑640×480 MJPEG短录制已验证。
- 小手机：SOYES K99，Android 9；OTG USB枚举及授权由用户确认通过。
- 手机第一轮320×240：用户确认有画面、帧数增长；回接电脑读到552帧、末段回调约9.8帧/秒，没有取流错误，已保存实际JPEG。请求5帧/秒不代表设备严格按该速度输出，实际回调单独记录。
- 第一轮证据：`output/usb_camera_check/phone-20261012-234119/summary.json`和该目录JPEG/JSONL。
- 当前v0.2默认640×480、请求不高于10帧/秒；允许选择320×240、1280×720、1920×1080。只使用相机实际报告的MJPEG模式与5～10帧列表，未提供则明确报错，不自动伪装降档成功。640/720P/1080P的手机实物验证按后续记录，不能从模式菜单宣称通过。

## 怎么操作

1. 手机接电脑、已允许USB调试时，运行`build_uvcpreview.py`构建；用ADB安装生成的`output/usb_camera_check/zhixing-uvcpreview.apk`，打开“知行回路外接相机”。
2. 允许相机权限；拔电脑线，改接手机→OTG→相机原配USB线。允许该应用访问摄像头，必要时点“开始预览”。仅匹配145F:02EC，不读取内置相机。
3. 手机显示收到的帧数、分辨率及数据是否过期；本地写有界JSONL和一张NV21转JPEG，外设插拔/授权/取流失败均进入记录。首帧8秒未到则关闭取流；每轮最多120秒，退出页面也停止并释放设备。
4. 测试后手机接回电脑，运行`collect_uvcpreview.py`，只读取本项目开发版应用自身日志和图片。每轮单独保存，不能拿旧320成功替代新640失败。该开发APK允许`run-as`读它自己的数据；不读取其他应用私有文件。

日志包括手机单调时间、帧计数、分辨率、请求帧率、实际回调率/最后一帧年龄、格式协商结果、错误、接入/断开和保存图片事件。不记录USB设备序列号或音频。当前只是相机诊断，不等于整车传感器历史记录。

停止条件：无画面/连续停止更新、手机卡死重启、供电不稳时停止本轮取流；驱动板电池保持断开。高分辨率未长期验证，不接入运动决策。
