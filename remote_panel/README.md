# 电脑状态页与云台手动控制

网页 → 电脑服务 → CH32 → 两只SG90。当前车辆运动禁用，驱动电池断开；独立车载供电、手机无线访问及整车遥控另行接入。

运行server.py --serial COM5 --bind 127.0.0.1 --port 8766，地址见runtime.json。串口仅本服务占用。开启后用滑块或加减调整，回中和停止均读主控回执。页面打开、刷新或重新连接不会自动开启。

水平PA8、俯仰PB0；供电沿用当前开发板+5V/GND。位置数值是相对指令，非实测角度；两轴限定1000–2000us（机械极限未校准），渐变过渡。板5V双负载长时能力未验收。

页面隐藏、关闭、刷新请求停止；页面心跳失联约1.8秒请求停止，电脑/串口失联时主控约3秒停PWM。停止PWM不等于切断舵机电源，物理拔线超时尚未实测。停止优先，取消排队请求；只有固定状态查询和云台专用指令，没有任意串口透传或车辆运动接口。原只读版留在readonly-20261013-backup，旧POST405说明不适用于当前版。

主控编译/烧录/读回通过；浏览器开启、两轴目标、回中、停止及刷新停止已获真实主控反馈。实体动作待本人观察；不能用PWM数值替代角度和长期稳定验收。通信新鲜度与整组遥测更新时间分别判断。

本轮原ToF报异常、超声有效，根因未定。下一步用户小幅调整观察两轴；卡住、线绷紧、持续抖动、板重启或停止无效时拔开发板USB。

## 2026-10-13摇杆更新

二维摇杆可斜向同时调整，松手保持位置，方向键每次5单位。默认幅度60%，可选40/60/80/100%；在界面幅度内限制滑块、摇杆与按钮。全幅不代表机械端点已安全验收，逐步试探，遇支架或线缆限制立即停止。当前上板r1_gimbal_wide，旧网页文件备份manual-before-joystick-20261013。

## 2026-10-13外接相机

开启画面后可选择清晰度320×240/640×480/720P/1080P及目标帧率5/10/15/20/30。选择停顿500毫秒后自动重新取流，无需应用按钮。源仅为145F:02EC视频接口，经FFmpeg DirectShow处理；不读内置相机/音频。JPEG实际尺寸逐帧核对，后端新帧发布限速，浏览器单帧解码时刻估算实际预览FPS。实际速度可能低于目标，页面分开显示。画面过期或关闭清空，断开后不自动重开。页面隐藏/关闭发停止请求；10秒无帧请求或2秒无新帧则关闭相机进程。切换与关闭不会绕过CH32运动许可。当前手机无线链路仍未接入。实测证据见output/camera-panel-20261013/summary.json及output/auto-camera-diagnostics-20261013/verification.json。

## 2026-10-13记录与回放

开画面并连接主控后，开始记录 → 停止并保存 → 选历史记录 → 打开回放 → 播放/暂停/拖动时间轴。保存于recordings/时间编号/：video.mjpeg原始JPEG视频流、frames.jsonl真实帧接收时间/偏移索引、telemetry.jsonl主控原始状态及数据年龄、session.json汇总。通过本页回放，普通MP4导出尚未实现。按电脑单调接收时刻对齐，非硬件同步；回放展示该帧之前的状态及时间差，过期数据不冒充新鲜距离。只记录新状态，数据更新率取决于主控真实回传，不能按视频帧率推算传感器采样率。

录制不会发运动指令，帧队列32，单段最多600秒/512MB。丢帧计数保留；低磁盘、取流中断、关闭画面/离开页面结束保存。录制中切换画质会保存旧段，并在新画面有效后继续录制新段；显式停止或离开页面不会重新启动录制。记录本地保存、不录音、不上传。强制进程退出留下的未完成记录按中断处理；长期和异常插拔/断电恢复未验收。网页回放数据地址只接受服务生成的固定时间编号，无任意文件读取。证据见output/recording-check-20261013/verification.json。

## 2026-10-13自动应用与完整记录方向

诊断区移到页面最下面并默认折叠。通信原始日志自服务启动自动保存到diagnostics/时间编号/，独立于录像按钮：TX_ATTEMPT、TX_ACCEPTED、RX逐字节Base64保存，保留换行及无法解码的字节；解析后的状态单独保存，不覆盖原始数据。TX_ACCEPTED仅指电脑串口写入返回的字节数，不等于主控已执行，执行情况需结合回执。UI操作、串口错误及相机切换/首末帧时间另外记录；控制会话凭据不入日志。16MiB分段保留旧文件，无自动覆盖。日志写入故障会暂停操作并请求停止；该分支未做真实满盘硬件验收。

实测选择720P/10自动生效，录像中切换640×480/15旧段106帧、新段370帧并自动续录，两段无队列丢帧；字节还原、分段及事件顺序核验通过。早期本轮日志20261013-110010-253e7e有相机首帧事件覆盖seq字段问题，原件保留，不用于严格连续序号判断；已修正帧号为frame_seq及事件保留字段，新运行20261013-110903-c5a0ad序号连续核验通过。

当前仍是电脑原型：摄像画面需开始记录；到单段时长/容量上限后不会自动续段。原始通信持续自动记录，但未发送到电脑的CH32内部/电机驱动串口事件无法捕获。最终车载独立记录契约及未完成项见[车载独立记录契约](./车载独立记录契约.md)，不能以此原型宣称小手机全程记录已经完成。下一步打通车载手机与主控通信及独立供电，再实现自动录像分段、故障恢复与导出；有丢帧/缺字节/异常结束必须标记不完整，禁止宣称无损。
