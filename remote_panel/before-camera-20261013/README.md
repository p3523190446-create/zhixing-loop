# 电脑状态页与云台手动控制

网页 → 电脑服务 → CH32 → 两只SG90。当前车辆运动禁用，驱动电池断开；独立车载供电、手机无线访问及整车遥控另行接入。

运行server.py --serial COM5 --bind 127.0.0.1 --port 8766，地址见runtime.json。串口仅本服务占用。开启后用滑块或加减调整，回中和停止均读主控回执。页面打开、刷新或重新连接不会自动开启。

水平PA8、俯仰PB0；供电沿用当前开发板+5V/GND。位置数值是相对指令，非实测角度；两轴限定1000–2000us（机械极限未校准），渐变过渡。板5V双负载长时能力未验收。

页面隐藏、关闭、刷新请求停止；页面心跳失联约1.8秒请求停止，电脑/串口失联时主控约3秒停PWM。停止PWM不等于切断舵机电源，物理拔线超时尚未实测。停止优先，取消排队请求；只有固定状态查询和云台专用指令，没有任意串口透传或车辆运动接口。原只读版留在readonly-20261013-backup，旧POST405说明不适用于当前版。

主控编译/烧录/读回通过；浏览器开启、两轴目标、回中、停止及刷新停止已获真实主控反馈。实体动作待本人观察；不能用PWM数值替代角度和长期稳定验收。通信新鲜度与整组遥测更新时间分别判断。

本轮原ToF报异常、超声有效，根因未定。下一步用户小幅调整观察两轴；卡住、线绷紧、持续抖动、板重启或停止无效时拔开发板USB。

## 2026-10-13摇杆更新

二维摇杆可斜向同时调整，松手保持位置，方向键每次5单位。默认幅度60%，可选40/60/80/100%；在界面幅度内限制滑块、摇杆与按钮。全幅不代表机械端点已安全验收，逐步试探，遇支架或线缆限制立即停止。当前上板r1_gimbal_wide，旧网页文件备份manual-before-joystick-20261013。
