# 手机无线状态页 · 第一版

临时链路：CH32 → 电脑USB串口 → 同网手机浏览器。车载独立运行、视频和遥控尚未接入，不将本页称为已完成手机遥控。

页面读取真实距离、预警距离、声音模式、电压、四轮速度、运行时间和故障；与第二屏相同的官方轮序。连接断开或采集超过5秒未更新清空数值；距离图仅使用实物有效读数，中断不补造数据。

运行server.py --serial COM5 --bind <本机无线IPv4> --port 8766。地址写在runtime.json。同一时间仅一个串口程序访问COM5，不同时开视觉桥接/别的调试程序。本页只使用源码固定的6条状态查询，无运动/设置写入命令、无任意串口透传；POST返回405。

局域网页面带临时随机路径，重启服务需新地址。浏览器访问与车端串口分别显示连接状态；校园网隔离或防火墙阻断会使手机无法打开，本机能打开不代表手机已通过。

下一步：同一Wi-Fi/热点上的本人手机打开页面，转动现有旋钮或改变目标位置，核对真实状态更新。停止条件：页面数值过期、串口被其他进程占用或模块错误，先处理连接，不追加遥控运动。
